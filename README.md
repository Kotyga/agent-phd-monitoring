# phd-admission-monitor

> Внимание: этот проект не является официальным сервисом приёмной комиссии. В данных и расчётах могут содержаться ошибки; автор не несёт ответственности за любые решения, принятые на основе результатов этого инструмента.

Автоматический парсер списков аспирантуры с расчётом статуса поступления по приоритетам.

## Что делает проект

- Загружает страницы с конкурсными списками и количеством мест.
- Нормализует данные в CSV.
- Считает статусы:
  - `green` — проходит на это направление.
  - `yellow` — проходит по конкурсу, но закреплен в более высоком приоритете.
  - `orange` — не проходит сюда, но проходит в другое направление.
  - `red` — совсем никуда не проходит.
- Генерирует HTML-отчёт с поиском по уникальному коду.
- Формирует Excel-снимок (если установлен `openpyxl`).

## Как пользоваться таблицей

1. Запустите обновление данных:

```bash
python3 src/run_pipeline.py
```

2. Откройте файл `reports/index.html` в браузере.

3. В блоке "Проверка по уникальному коду":
   - введите `Уникальный код`;
   - нажмите `Проверить`;
   - получите ответ, куда человек проходит сейчас (если проходит), тип места и вид документа.

4. В таблицах по конкурсным группам:
   - `Уникальный код` — идентификатор абитуриента;
   - `Вид документа` — `Оригинал` или `Копия`;
   - `Место в рейтинге` — позиция в исходном списке группы;
   - `Приоритет` — чем меньше число, тем выше приоритет;
   - `Статус` — цветовая оценка текущей ситуации.

5. Интерпретация цветов:
   - `green` — проходит сюда и закреплён здесь;
   - `yellow` — проходит по конкурсу, но закреплён в более высоком приоритете;
   - `orange` — не проходит сюда, но проходит в другое направление;
   - `red` — совсем никуда не проходит.

6. Важно:
   - расчёт делается по текущему снимку списков, это не официальный приказ;
   - при обновлении списков статус может измениться;
   - поле `Оригинал/Копия` отображается, но отдельно не фильтрует распределение.

## Запуск

```bash
python3 src/run_pipeline.py
```

Повторный запуск по уже скачанным данным:

```bash
python3 src/run_pipeline.py --skip-fetch
```

## Артефакты

- `data/raw/` — сырые HTML + `manifest.json`
- `data/normalized/applicants.csv`
- `data/normalized/places.csv`
- `data/results/by_direction.csv`
- `data/results/by_code.csv`
- `reports/index.html`
- `reports/admission_snapshot.xlsx` (или `reports/admission_snapshot.csv`, если нет `openpyxl`)
- `logs/pipeline.log`

## Автообновление через cron

Пример каждые 30 минут:

```cron
*/30 * * * * cd /home/user/phd-admission-monitor && /usr/bin/python3 src/run_pipeline.py >> logs/cron.log 2>&1
```
